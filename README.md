# English

## Unlocking JVM Secrets: Analyzing and Optimizing Java Apps

The JVM offers powerful introspection capabilities through advanced tools like JMX, Flight Recorder, Mission Control, and the utilities in your JDK’s bin folder.

Mastering Java application monitoring and optimization is key to building efficient software. 

In this talk, you’ll gain hands-on skills to monitor, diagnose, and optimize your Java applications with confidence using OpenJDK's built-in tools.

### Examples
Explore the `getting-started` and `other-cases` directories, where you'll find basic and advanced examples.
